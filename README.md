# Генератор QR-кодов Wi-Fi

Этот проект представляет собой простое веб-приложение, которое позволяет пользователям генерировать QR-коды для конфигураций сети Wi-Fi. Пользователи могут ввести SSID, пароль и тип шифрования, и приложение сгенерирует QR-код, который можно сканировать смартфонами или другими устройствами для автоматического подключения к указанной сети Wi-Fi. Приложение сохраняет ранее введенные SSID для удобства.

## Возможности

*   **Генерация QR-кодов Wi-Fi:** Легко создавайте QR-коды, содержащие учетные данные сети Wi-Fi.
*   **Сохранение SSID:** Автоматически сохраняет SSID в локальном хранилище для быстрого доступа к часто используемым сетям.
*   **Переключение видимости пароля:** Возможность показать/скрыть пароль для более удобного ввода.
*   **Загружаемые QR-коды:** Сгенерированные QR-коды можно загрузить в виде изображений PNG.
*   **Адаптивный дизайн:** Удобный пользовательский интерфейс, который адаптируется к различным размерам экрана.

## Используемые технологии

*   [`Flask`](app.py:1) - Веб-фреймворк для Python.
*   [`qrcode`](app.py:2) - Библиотека для генерации QR-кодов.
*   [`Pillow`](app.py:3) (PIL) - Библиотека обработки изображений Python для манипуляций с изображениями.
*   [`HTML`](templates/index.html), [`CSS`](static/style.css), [`JavaScript`](static/script.js) - Фронтенд-разработка.

## Установка и настройка

Чтобы запустить этот проект локально, выполните следующие шаги:

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/UniQlow17/wifi_qr_generator.git
    cd wifi_qr_generator
    ```

2.  **Создайте виртуальное окружение** (рекомендуется):
    ```bash
    python -m venv .venv
    source .venv/bin/activate  # В Windows используйте `.\.venv\Scripts\activate`
    ```

3.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```

## Использование

### Запуск без Docker

1.  **Запустите приложение Flask:**
    ```bash
    python app.py
    ```

2.  **Откройте приложение:**
    Откройте веб-браузер и перейдите по адресу `http://127.0.0.1:5000/`.

3.  **Сгенерируйте QR-код:**
    *   Введите SSID (имя сети) Wi-Fi. Вы можете выбрать ранее сохраненный SSID или ввести новый.
    *   Введите пароль (если применимо).
    *   Выберите тип шифрования (WPA/WPA2, WEP или None).
    *   Нажмите кнопку "Generate QR Code".

4.  **Загрузите QR-код:**
    После генерации QR-кода вы можете нажать на ссылку "Download QR Code", чтобы сохранить его как изображение PNG.

### Запуск с использованием Docker

1.  **Соберите образ Docker:**
    ```bash
    docker build -t wifi_qr_generator .
    ```

2.  **Запустите контейнер Docker:**
    ```bash
    docker run -p 5000:5000 wifi_qr_generator
    ```
    Приложение будет доступно по адресу `http://localhost:5000/`.
